# Postman collection

`crawlerdata.postman_collection.json` has one request per CrawlerData endpoint (Google Search with AI Overview, Search by city, News, Images, Local, Autocomplete, and the three Google Shopping endpoints).

1. In Postman: **Import** and choose the file (or paste its raw GitHub URL).
2. Open the collection's **Variables** and set `api_key` to your CrawlerData API key. Create one at https://app.crawlerdata.com; new accounts with a verified work email get free trial credits.
3. Send a request. Each request costs 1 credit (Shopping sellers: 1 credit per 10 sellers returned). Failed requests are not charged.

API reference: https://crawlerdata.com/apis/google-search-api
